# Changelog

All notable changes to OpenTrace are documented here.

## 0.1.0 — Initial public MVP

- Add local SQLite session ledger and CLI.
- Add manual token usage and estimated cost recording.
- Add Git changed-path capture and check-result recording.
- Add JSON and CSV exports.
- Add opt-in local Claude Code and Codex usage importers.
- Add loopback-only read-only dashboard.
- Add optional read-only MCP server.
- Add tests, CI matrix, privacy documentation, architecture notes, and contribution guidance.

This is an initial release candidate. Agent log format compatibility is best-effort and should be validated against more sanitized fixtures before a stable package release.
